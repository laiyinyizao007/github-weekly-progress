## Overview

Green Compass is an AI-powered carbon footprint tracking and management platform built for enterprises. It helps organisations monitor, analyse, and reduce their carbon emissions across operations, supply chains, and product lifecycles.

## Key Features

- Real-time carbon data ingestion from multiple sources
- AI-assisted emission factor matching and categorisation
- Report generation aligned with GHG Protocol and ISO 14064
- Multi-tenant SaaS architecture with role-based access

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | TypeScript, React, Tailwind CSS |
| Backend | Node.js, PostgreSQL |
| AI | Claude API for data extraction and report generation |
| Infra | Docker, GitHub Actions |
