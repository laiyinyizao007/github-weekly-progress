# 📓 Obsidian Second Brain

**Claude Code + Obsidian second-brain starter kit (PARA, Git, mobile access)**

`Obsidian` · `Claude Code` · `MCP`

---

## Overview

A starter kit for building a second brain in Obsidian, wired up with Claude Code via MCP for AI-assisted note-taking and synthesis. Organised with the PARA method (Projects, Areas, Resources, Archive), version-controlled with Git, and accessible from mobile via Obsidian Sync or Git-based sync.

## Key Features

- PARA folder structure with templates for each category
- Claude Code MCP integration for in-vault AI assistance
- Git-based version control with automated daily commits
- Mobile sync via Obsidian Sync or Working Copy (iOS)
- Dataview dashboards for active projects and review queues

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Notes | Obsidian |
| AI | Claude Code + MCP |
| Version control | Git |
| Automation | Shell scripts, cron |
