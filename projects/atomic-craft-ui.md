# 🎨 Atomic Craft UI

**Atomic UI component library**

`TypeScript` · `React` · `Design System`

---

## Overview

Atomic Craft UI is an internal React component library built on atomic design principles. It provides a consistent design system across multiple SaaS products — from carbon tracking to health management — with a shared token system, theming support, and full TypeScript types.

## Key Features

- Atomic design architecture (atoms → molecules → organisms)
- Design token system with light/dark theme support
- Full TypeScript types and JSDoc documentation
- Storybook integration for component development and review
- Shared across Green Compass and Fidelity Craftsmen products
