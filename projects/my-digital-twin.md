# 🌐 Digital Twin

**Interactive portfolio — D3.js force-directed skill graph, i18n, Supabase**

`TypeScript` · `React` · `D3.js`

---

## Overview

Digital Twin is an interactive personal portfolio that visualises skills and projects as a force-directed graph. Rather than a static page, it lets visitors explore connections between technologies, projects, and roles — built with D3.js for the graph layer and Supabase for dynamic content.

## Key Features

- Force-directed skill graph built with D3.js — nodes are skills, edges are project relationships
- i18n support (English / Chinese)
- Supabase-backed content for easy updates without redeployment
- Responsive layout with smooth physics simulation
- Project detail panels on node click

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | TypeScript, React, D3.js |
| Data | Supabase (PostgreSQL) |
| i18n | react-i18next |
| Build | Vite |
