## Overview

LifeOS is a personal operating system that uses LLMs to orchestrate daily life workflows. It connects Google Calendar, Notion, and other tools into a unified event-driven layer — so that tasks, notes, and schedules flow between systems automatically without manual copy-paste.

## Key Features

- LLM-orchestrated automation across connected apps
- Google Calendar ↔ Notion bidirectional sync
- Natural language task capture and routing
- Supabase-backed event log and state store
- React dashboard for monitoring and manual overrides

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | TypeScript, React |
| Backend | Supabase (PostgreSQL + Edge Functions) |
| AI | Claude API for intent parsing and workflow orchestration |
| Integrations | Google Calendar API, Notion API |
